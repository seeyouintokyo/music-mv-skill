# 《月亮在等你》MV 分镜

- 项目：`moon-mv/`
- 画布：1080×1920 竖屏，30 fps（`tokens.canvas`）
- 总长：57 秒 / 1710 帧（≤ 60 秒）
- 歌：用户在网页版生成的《月亮在等你》带人声 mp3（`MV套件/月亮在等你.mp3`，83.91s，BPM 92）；风格与歌词取 `MV套件/MV歌曲基底.md`。成片取该音频前 57s，结尾 2s 淡出。
- 主意象：月亮（月相：弯 → 渐圆 → 满 → 收回弯），全片不换题材
- 颜色 / 字号 / 间距 / 动画节奏：一律取 `src/tokens.ts`

## 时间怎么来的

- 初版按 BPM 92 估算（一句 ≈ 8 拍 × 60 ÷ 92 ≈ 5.2 秒），现按真实歌的语音转写实测时间重排。
- 实测人声：前奏 0–10.8s（纯器乐）；主歌 10.8–28.75s；副歌 28.95–49.9s；尾句 50.5–55.0s；55s 后为纯器乐尾奏。
- 段落边界据此定为 前奏 10.8s + 主歌 18.2s + 副歌 21s + 尾奏 7s = 57s。副歌人声 28.95s 与画面闪白 29s 天然重合。
- 歌长 83.91s（> 60s），按制作要求只取一段：这里取前 57s（保留完整 10.8s 前奏）。**没有按「第一句前 2 秒」裁**：若从 8.8s 起播，人声会整体提前 8.8s，与画面全部错开。音轨未物理裁剪，靠 Composition 57s 自然截断 + `audio.fadeOut` 结尾 2s 淡出；歌词时间轴与节拍分析均以 MV 开头为 0，无需减偏移。
- 逐句时间写在 `歌词时间轴.json`（段内两句按 ASR 分段等分拆开，误差约 ±0.5s），按第 4 步出 20 秒预览后由用户听校准。

## 画面与动画约束

- 只用代码画：圆、线、矩形、SVG path、渐变、文字。不用外部图片、不用 3D、不画人物、不联网加载素材。
- 主歌安静：元素少、动作慢、颜色暗；副歌爆发：元素更多、更亮、更大，画面整体放大一点。
- 段落切换统一 `motion.sceneFade` 12 帧；缓动 `Easing.bezier(0.22, 1, 0.36, 1)`。
- 跟节拍：`useAudioData` + `visualizeAudio` 取低音，驱动月亮缩放与光圈扩散，幅度 ≤ `motion.beatScale` 0.08。
- 歌词：中间偏下，`size.lyric` 72px；当前句完整显示并高亮，上一句变淡上移退出，整句淡入、不逐字跳。主歌句单行；副歌句在歌词自带的空格（换气点）处折成两行，避免 12 字长句溢出 888px 可用宽度。
- 四周留 `space.safe` 96px。
- 随机星点用 `random('种子')` 固定；禁用 CSS 动画 / `setTimeout` / `Math.random()`。
- 结尾 `audio.fadeOut` 60 帧（2 秒）音频与画面同步淡出。

## 音频与校准

- 音源：`MV套件/月亮在等你.mp3`（83.91s，带人声）；占位伴奏已备份为 `public/song.placeholder.mp3`。另一首 `月亮在等你 (1).mp3`（157.55s）是长版，未采用。
- 待用户听 20 秒预览确认逐句歌词是否有早/晚，按反馈微调 `歌词时间轴.json` 后重渲染。
