# 示例：《月亮在等你》57 秒竖屏 MV

这是用本 Skill 做完的**真实案例**，源码、分镜、歌词时间轴全部在此，可直接对照。

## 结果

| 项 | 值 |
|---|---|
| 成片 | 57.05 秒 / 1080×1920 / 30fps / h264+aac / 约 13 MB |
| 结构 | 前奏 10.8s + 主歌 18.2s + 副歌 21s + 尾奏 7s = 57s |
| 主意象 | 月相：峨眉 → 上弦 → 盈凸 → 满月 → 收回一弯 |
| 歌 | 用户在网页版生成的带人声 mp3，83.91 秒，BPM 92 |
| 画面 | 四屏全部由圆、SVG path、线、渐变、文字代码画出，零外部素材 |

静帧见 `../../assets/preview/frame-120.png`（前奏）、`frame-500.png`（主歌）、`frame-1100.png`（副歌）。

## 为什么这个案例值得看

**1. 时间不是猜的。** 歌经 ASR 转写实测：人声 10.8 秒起、主歌到 28.75 秒、副歌 28.95 秒起、55 秒后纯器乐尾奏。四段边界据此定为 10.8 / 18.2 / 21 / 7 秒。副歌人声 28.95 秒与画面 29 秒的入屏闪白天然重合。

**2. 长歌没有硬裁。** 歌 83.91 秒 > 60 秒，按常规做法应从第一句前 2 秒（8.8 秒）起播。但那样人声会整体提前 8.8 秒，四屏全错开。这里保留完整前奏，靠 Composition 57 秒自然截断 + 结尾 2 秒淡出，音轨未物理裁剪。判断和理由写在 `分镜.md`。

**3. 逐屏截图查出的两个问题都修了。**
- S1 歌名贴到月亮顶边 → 挪开 `top`。
- S3 十二字长句「缺了的那一半 只是光还没走」被浏览器硬折，末行只剩「走」→ 改成优先按歌词自带空格折行。

## 怎么跑

仓库**不带音频文件**（用户的歌版权归用户）。要复现，自备一首带人声的 mp3：

```bash
# 在本仓库根目录执行
cd ../..
node scripts/scaffold.mjs /tmp/moon-demo --song 你的歌.mp3 \
  --lyrics examples/moon/歌词.txt --title "月亮在等你"
cd examples/moon
cp src/scenes/*.tsx     /tmp/moon-demo/src/scenes/
cp src/components/*.tsx /tmp/moon-demo/src/components/
cp src/hooks/*.ts       /tmp/moon-demo/src/hooks/
cp src/timing.ts src/tokens.ts src/Video.tsx src/Root.tsx /tmp/moon-demo/src/
cp 歌词时间轴.json 分镜.md /tmp/moon-demo/
cd /tmp/moon-demo && npm install --registry=https://registry.npmmirror.com
npx tsc --noEmit
npx remotion render src/index.ts Main out/mv.mp4
```

`src/timing.ts` 是本案例的**硬编码版**（10.8 / 18.2 / 21 / 7 秒），覆盖后就不读 `content.ts` 了；换成别的歌请用 `scaffold` 自带的 `content.ts` 版本。

本目录的价值是**当答案对照**：`src/timing.ts` 的四段秒数、`歌词时间轴.json` 的九句、`src/scenes/` 的四屏写法，都是跑通的版本。
