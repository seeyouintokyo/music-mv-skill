# 分镜模板

- 项目：`<项目目录>/`
- 画布：1080×1920 竖屏，30 fps（`tokens.canvas`）；用户要横屏才换 `tokens.canvasHorizontal`
- 总长：≤ 60 秒
- 歌：`<来源与文件名>`，`ffprobe` 实测时长 `<N>` 秒
- 主意象：`<从歌词里挑一个：月亮 / 星空 / 海浪 / 城市灯光…… 全片不换>`
- 颜色 / 字号 / 间距 / 动画节奏：一律取 `src/tokens.ts`

## 分镜表

| 屏 | 段落 | 时间 | 画面上有什么、怎么动 | 这段的歌词 |
|---|---|---|---|---|
| S1 | Intro 前奏 | | | 无词，只出歌名 |
| S2 | Verse 主歌 | | 元素少、动作慢、偏暗；主意象随 4 句变化 | |
| S3 | Chorus 副歌 | | 入屏闪白 ≤6 帧；更亮、更大、更多层；整体放大约 4% | |
| S4 | Outro 尾奏 | | 元素反向收拢；最后 2 秒音画同步淡出 | |

## 时间怎么来的

- 跑 `scripts/probe_song.py` 拿静音间隙，用 ASR 转写量出第一句与副歌第一句的真实时间。
- 段内句子按等分拆开只是初稿，误差约 ±0.5 秒，必须让用户听 20 秒预览校准。
- 不要按 BPM 猜完就渲染整片。

## 歌长于 60 秒时

默认从第一句歌词前 2 秒截到第一遍副歌结束，结尾 2 秒淡出。
**但先算对齐再决定裁不裁**：如果原曲的副歌人声已经和画面爆发点天然重合，保留完整前奏、靠 Composition 自然截断更准；一旦裁掉开头，人声会整体提前，四屏全错开。
截取用 `<Audio trimBefore={开始秒数 * fps} />`，歌词时间轴和节拍分析的帧号要一起减偏移。

## 画面与动画约束

- 只用代码画：圆、线、矩形、SVG path、渐变、文字。不用外部图片、3D、人物、联网素材。
- 动画只能由当前帧号或音频数据算出来；禁用 CSS 动画、`setTimeout`、`Math.random()`。
- 鼓点驱动主体缩放幅度 ≤ `tokens.motion.beatScale`（0.08）。
- 写完一屏截一张图检查：文字溢出、元素重叠、单字孤行、画面空白。
